## Contenido

- `sql/`: scripts de la base de datos MySQL.

## Ejecución de los scripts

Requisito: MySQL 8.0 (también funciona en MariaDB / XAMPP).
Ejecutar en este orden:

1. `01_creacion_sigi.sql`: crea la base `sigi` y sus 9 tablas.
2. `02_insercion_sigi.sql`: carga los datos de prueba.
3. `03_consultas_sigi.sql`: consultas del sistema.
4. `04_borrado_sigi.sql`: borrados puntuales y vaciado completo.
